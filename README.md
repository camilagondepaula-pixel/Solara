Solara — Élixir Dourado

> *Onde a floresta encontra a hora dourada.*

Landing page de produto de luxo para o **Élixir Dourado**, um sérum facial inspirado na biodiversidade amazônica e na luminosidade brasileira.

[Ver site ao vivo](https://camilagondepaula-pixel.github.io/Solara/)**

---

Sobre o Projeto

O Solara é um projeto de design web focado em comunicar sofisticação e identidade brasileira. A página apresenta o produto com uma estética editorial de luxo, inspirada em marcas como La Mer e Charlotte Tilbury — com alma 100% brasileira.

---

Estrutura do Projeto

```
Solara/
├── index.html        # Página principal
├── hero.png          # Imagem principal (hero section)
├── lifestyle.png     # Foto de lifestyle do produto
├── ingredients.png   # Foto dos ingredientes botânicos
└── frasc.png         # Frasco do produto sobre mármore
```

---

Design

- **Paleta:** dourado âmbar `#C8872A`, creme `#F5F0E8`, marrom escuro `#1C1208`
- **Tipografia:** Cormorant Garamond (serif elegante) + Jost (sans-serif clean)
- **Estilo:** editorial de luxo, minimalista, com animações suaves de scroll

-

Ingredientes em Destaque

| Ingrediente | Benefício |
|---|---|
| Óleo de Buriti | Brilho dourado natural, rico em betacaroteno |
| Extrato de Maracujá | Hidratação profunda e vitalidade |
| Óleo de Moringa | Barreira de hidratação sedosa |
| Nanopartículas de Ouro | Luminosidade imediata |



Tecnologias

- HTML5 semântico
- CSS3 (variáveis, grid, animações, parallax)
- JavaScript vanilla (Intersection Observer para scroll reveal)
- Google Fonts
- GitHub Pages (hospedagem gratuita)



Como Usar Localmente

Basta abrir o arquivo `index.html` diretamente no navegador — não precisa de servidor ou instalação.

bash
Clone o repositório
git clone https://github.com/camilagondepaula-pixel/Solara.git

Abra no navegador
open index.html


Imagens Necessárias

Para o site funcionar corretamente, os seguintes arquivos de imagem devem estar na raiz do repositório:

- `hero.png` — foto hero (tela cheia)
- `lifestyle.png` — foto do produto em uso
- `ingredients.png` — foto dos ingredientes
- `frasc.png` — foto do frasco
